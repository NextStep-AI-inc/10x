=== t0 (per-account identity absent from usage --json) ===
Launched against a freshly seeded agent dir carrying one OAuth credential
whose usage-report metadata omits accountId/email (see
tier-providerOnly-usage-snapshot.json). Same normal Release build as t2 (PID
41624); extension IS loaded (four `-e ...index.ts` RPC clients spawned,
