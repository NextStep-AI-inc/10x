# 10x macOS GUI V1 Implementation Plan (Plan 2 of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the native 10x macOS application around the completed OmpKit package, including the floating project/session rail, live agent workspace, modal search, continuous-form Settings, native approvals, and V1 tool rendering.

**Architecture:** A conventional Xcode macOS application target depends on the local `OmpKit` Swift package. A `@MainActor` app model owns navigation and feature models, while actors/services own filesystem scans, OMP processes, search, and configuration commands. The UI is split by product feature and uses a small shared design layer for the approved graphic-modernist tokens, ghost actions, and frameless corner cards.

**Tech Stack:** Xcode 26.6, Swift 6.1+, SwiftUI, Observation, Swift Testing, Foundation/AppKit/CoreText, local OmpKit package, Ruby `xcodeproj` 1.27.0 for deterministic project generation. No runtime third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-08-24-10x-omp-macos-gui-design.md`

## Global Constraints

- Read the spec above before every task; it is the visual and behavioral authority.
- macOS deployment target is **15.0**. Compile in Swift 6 language mode with complete concurrency checking.
- Tested OMP version is **18.0.4**, RPC protocol **v2**.
- The V1 acceptance target is light appearance with a pure `#FFFFFF` canvas.
- Palette: near-black `#0C0C0B`, cyan `#00A7C4`, signal red `#FF3B24`, yellow `#FFC400`, muted text `#6B6B66`, separator `#E5E5E1`, hover neutral `#F7F7F5`.
- Chillax is limited to major titles and accents. SF Pro is the shell/body face. SF Mono is used for code, paths, branches, repositories, worktrees, commands, diffs, logs, and tool output.
- No decorative background shapes, dots, stripes, large gray accent fills, application shadows, or warm cream/orange surfaces.
- Buttons are borderless by default. Preferred actions are accent-colored ghost actions. Borders are limited to isolated composers, modals, inputs, and native controls.
- Projects and sessions live in the expanded rail. Search is modal. None is a standalone route.
- Work in the existing `codex/macos-gui-v1` worktree. Do not modify the main checkout. Use conventional, atomic commits and never merge without Tanner's instruction.
- Do not enable App Sandbox in V1: the local developer tool must spawn the user-selected OMP executable and read project/session files outside its container.
- Do not add runtime package dependencies. Render Markdown with Foundation `AttributedString(markdown:)` and dedicated code/tool views.
- Run `ruby scripts/generate_xcodeproj.rb` after adding or removing source/resource files and before every `xcodebuild` command so the committed project contains the current file set.

#!/usr/bin/env ruby
require "fileutils"
require "xcodeproj"

root = File.expand_path("..", __dir__)
project_path = File.join(root, "10x.xcodeproj")
FileUtils.rm_rf(project_path)
project = Xcodeproj::Project.new(project_path)
project.root_object.attributes["LastSwiftUpdateCheck"] = "2660"

app = project.new_target(:application, "10x", :osx, "15.0")
tests = project.new_target(:unit_test_bundle, "TenXAppTests", :osx, "15.0")
tests.add_dependency(app)

app_group = project.main_group.new_group("App")
test_group = project.main_group.new_group("Tests")

Dir.glob(File.join(root, "App/**/*.swift")).sort.each do |path|
  ref = app_group.new_file(path.delete_prefix(root + "/"))
  app.source_build_phase.add_file_reference(ref)
end
Dir.glob(File.join(root, "Tests/**/*.swift")).sort.each do |path|
  ref = test_group.new_file(path.delete_prefix(root + "/"))
  tests.source_build_phase.add_file_reference(ref)
end
snapshot_path = File.join(root, "Tests/TenXAppTests/ReferenceImages")
if File.directory?(snapshot_path)
  ref = test_group.new_file("Tests/TenXAppTests/ReferenceImages")
  tests.resources_build_phase.add_file_reference(ref)
end
["App/Resources/10x-wordmark.svg", "App/Resources/AppIcon.icon", "App/Resources/Fonts"].each do |path|
  ref = app_group.new_file(path)
  app.resources_build_phase.add_file_reference(ref)
end

package = project.new(Xcodeproj::Project::Object::XCLocalSwiftPackageReference)
package.relative_path = "OmpKit"
project.root_object.package_references << package
product = project.new(Xcodeproj::Project::Object::XCSwiftPackageProductDependency)
product.package = package
product.product_name = "OmpKit"
app.package_product_dependencies << product
build_file = project.new(Xcodeproj::Project::Object::PBXBuildFile)
build_file.product_ref = product
app.frameworks_build_phase.files << build_file

app.build_configurations.each do |config|
  config.build_settings.merge!({
    "PRODUCT_BUNDLE_IDENTIFIER" => "com.tannerpham.tenx",
    "PRODUCT_MODULE_NAME" => "TenXApp",
    "INFOPLIST_FILE" => "App/Info.plist",
    "SWIFT_VERSION" => "6.0",
    "SWIFT_STRICT_CONCURRENCY" => "complete",
    "MACOSX_DEPLOYMENT_TARGET" => "15.0",
    "ENABLE_APP_SANDBOX" => "NO",
    "ASSETCATALOG_COMPILER_APPICON_NAME" => "AppIcon",
    "CODE_SIGN_STYLE" => "Automatic"
  })
end
tests.build_configurations.each do |config|
  config.build_settings.merge!({
    "PRODUCT_BUNDLE_IDENTIFIER" => "com.tannerpham.tenx.tests",
    "PRODUCT_MODULE_NAME" => "TenXAppTests",
    "SWIFT_VERSION" => "6.0",
    "SWIFT_STRICT_CONCURRENCY" => "complete",
    "MACOSX_DEPLOYMENT_TARGET" => "15.0",
    "TEST_HOST" => "$(BUILT_PRODUCTS_DIR)/10x.app/Contents/MacOS/10x",

  })
end

project.save

```swift
import SwiftUI

enum TenXPalette {
    static let canvasHex = 0xFFFFFF
    static let nearBlackHex = 0x0C0C0B
    static let cyanHex = 0x00A7C4
    static let signalRedHex = 0xFF3B24
    static let yellowHex = 0xFFC400
    static let mutedTextHex = 0x6B6B66
    static let separatorHex = 0xE5E5E1
    static let hoverNeutralHex = 0xF7F7F5

    static func color(_ value: Int) -> Color {
        Color(
            red: Double((value >> 16) & 0xFF) / 255,
            green: Double((value >> 8) & 0xFF) / 255,
            blue: Double(value & 0xFF) / 255)
    }
}
```

`CornerCard` draws only top-left and bottom-right strokes with `Canvas`; it accepts `color: Color` and `@ViewBuilder content`. `GhostActionStyle` applies transparent background, accent foreground, a 6-point visual radius only for hover feedback, and a minimum 28-point hit height. `TenXTypography` exposes `title(_:)`, `body(_:)`, and `mono(_:)`; title uses `.custom("Chillax-Regular", size:)` and the others use system faces. `BrandWordmark` loads the bundled SVG as `NSImage` and supplies the accessibility label `"10x"`.

`TenXApp.swift` initially renders a white `Text("10x")` canvas inside a `WindowGroup` with minimum size `960 × 640`.

The harness uses the test source path for recording and the committed resource

```swift
import AppKit
import SwiftUI
import Testing

final class SnapshotToken {}

@MainActor
func assertSnapshot<Content: View>(
    _ content: Content,
    name: String,
    size: CGSize = CGSize(width: 900, height: 600),
    sourceFile: String = #filePath
) throws {
    let host = NSHostingView(rootView: content.frame(width: size.width, height: size.height))
    host.frame = CGRect(origin: .zero, size: size)
    host.layoutSubtreeIfNeeded()
    guard let bitmap = host.bitmapImageRepForCachingDisplay(in: host.bounds) else {
        Issue.record("Unable to allocate snapshot bitmap")
        return
    }
    host.cacheDisplay(in: host.bounds, to: bitmap)
    guard let actual = bitmap.representation(using: .png, properties: [:]) else {
        Issue.record("Unable to encode snapshot PNG")
        return
    }
    let sourceDirectory = URL(fileURLWithPath: sourceFile).deletingLastPathComponent()
    let recordingURL = sourceDirectory
        .appendingPathComponent("ReferenceImages")
        .appendingPathComponent("\(name).png")
    if ProcessInfo.processInfo.environment["RECORD_SNAPSHOTS"] == "1" {
        try FileManager.default.createDirectory(
            at: recordingURL.deletingLastPathComponent(),
            withIntermediateDirectories: true)
        try actual.write(to: recordingURL)
        return
    }
    guard let referenceURL = Bundle(for: SnapshotToken.self)
        .url(forResource: name, withExtension: "png", subdirectory: "ReferenceImages") else {
        Issue.record("Missing reference image: \(name).png")
        return
    }
    #expect(actual == Data(contentsOf: referenceURL))
}
```
